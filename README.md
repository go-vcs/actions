GitHub Actions workflow engine and gitea-runner protocol server. Part of
[go-vcs](https://github.com/go-vcs), a light, secure Git forge.

Status: **not started**. The repository holds a licence, this README and a
package comment. It is milestone 5 of the
[design](https://github.com/go-vcs/forge/blob/main/docs/design.md): workflow
parsing and planning (matrix, `needs`, expressions) and the server side of the
gitea-runner protocol, reusable without the forge.
